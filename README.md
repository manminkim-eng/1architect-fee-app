## 📐 적용 기준

### 건축사 대가 (블루 테마)
- **공공발주사업에 대한 건축사의 업무범위와 대가기준** — 국토교통부고시 제2020-635호 (2020.09.14)
- **건축사법 제19조의3** (시행 2025.10.01)
- 별표3 건축물 종별 · 별표4 설계 대가요율 · 별표5 감리 대가요율 · 직선보간법(제16조) · 인증할증(제11조)

### 엔지니어링 대가 (틸그린 테마)
- **엔지니어링사업대가의 기준** — 산업통상자원부 고시 (2024.12.31)
- **엔지니어링산업 진흥법 제31조** (시행 2026.06.03)
- 별표1 건설부문(도로·철도·항만·상수도·하천) · 별표2 통신부문(그룹1~4) · 별표3 산업플랜트(화학·가스 ×1.25, 부대시설 ×0.813) · 별표4 시공상세도작성비(난이도 단순·보통·복잡)
- ※ 별표5 1장당 단가식(노임단가×매수)·상주감리(실비정액가산)은 자동요율 대상 아님(미탑재)

> 모든 법령은 국가법령정보센터(law.go.kr) 기준 현행 확인(2026-07-16). 인·허가 적용 시 원문 부칙 시행일을 직접 대조 권장.

## 🚀 GitHub Pages 배포 방법

저장소 루트에 아래 파일을 모두 업로드합니다.

```
📁 저장소 루트
├── index.html          ← 메인 앱 (단일 파일, React CDN)
├── manifest.json       ← PWA 매니페스트
├── sw.js               ← 서비스 워커
├── favicon.ico
├── og-image.png
└── icons/              ← PWA 아이콘 세트 (PNG 고정)
```

1. 저장소 → **Settings → Pages** → Source: Deploy from a branch → **main / root** → Save
2. 배포 URL: `https://manminkim-eng.github.io/1architect-fee-app/`
3. `sw.js` 캐시 때문에 옛 화면이 보이면 **Ctrl+Shift+R**(강력 새로고침)
